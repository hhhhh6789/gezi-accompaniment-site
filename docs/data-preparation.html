929 歌仔戏配对数据准备

更新日期：2026-10-22。本文是网页展示的唯一正文内容源，可独立使用；技术细节和证据按需查阅配套文档。

当前结论：929已验收完成。40首、60对、3316.363242633秒（约55分16秒）；训练／验证／测试32／4／4首、51／4／5对；正式微调尚未开始，参数更新0次。

1. 项目目标

将歌仔戏录音整理成来源可追溯、具有质量审核和训练输入核验证据的人声—伴奏配对数据，为后续伴奏生成模型微调做准备。逐首人工听验与按批次规则采用分别标注，未抽中者不记为逐首人工通过。原始录音、配对音频及来源/听验记录可供后续其他方法复用；模型专用特征按所用方法适配。

流程：完整录音 → 人声/伴奏分离 → 整首或自然段落配对 → 质量与输入核验 → 数据划分与交付。
