4. 必须保留的限制和历史异常

  • 人声轨伴奏残留及伪影仍在，Chroma/VQ不修复WAV；旋律语义、残留影响和生成质量未证明。
  • 没有独立干净双轨真值；共同边界和完整覆盖不等于所有分离细节精确对齐。
  • R0004旧RMS切点否决与后来35.5／46秒边界采用分别记录，不能互相替代。
  • R0004长度守卫和R0021重采样长度差异按原诊断留证，数值方法与原音不因整理改变。
  • R0005完整94.77秒、4739帧前向显存不足保持；局部窗口成功不改写全长失败。早期1506／1503帧整段例外按原输入路径交付。
  • 提示启用、混合长度、补齐扰动及声码器听验均限定到实际已测范围；完整作者加载器、REPA/MERT、恢复训练和正式训练未验证。
  • 来源权利未核实、小样本、录制场次未知、未系统检查声学近重复及测试材料曾用于技术排查的限制继续保留。
