1. 目标、路线与边界

目标是先用少量录音验证数据构建全流程，再扩大音频收集与处理，最终获得足量、来源可追溯、质量合格、时间对齐，并经 AnyAccomp 实际训练输入流程核验可用的歌仔戏人声—伴奏配对训练数据。只有孤立人声不能直接提供对应的戏曲配器、节奏和过门监督信号。

小规模流程验证：少量音频收集与下载 → 保存完整录音 → 分离 → 质量与对齐核验 → 按戏曲结构同步分段 → 保存配对唱段 → 训练输入兼容性核验。

通过后规模化建集：扩大音频收集与下载 → 对每份完整录音执行已验证的分离、核验、同步分段和配对流程 → 按训练输入规则组织并复核全部样本 → 数据划分与交付。小规模录音只是试流程的材料，不是本实验预定的最终数据规模。

只有小规模链路的分离质量、时间对齐、结构分段、配对关系与训练输入兼容性均通过，并由用户确认后，才按确定的来源清单和处理规模开展批量数据构建。听音大模型不是必需前置。完整录音和戏曲结构性长唱段始终保留；论文报告的训练片段范围不作为本实验的硬性分段上限。能否直接训练长片段，要由实际训练实现验证。

实验边界：本实验包括伴奏目标能否被训练流程读取、对齐并用于计算损失的兼容性验证，必要时进行一个批次/一步的临时冒烟测试；这只是数据可用性的证据，不作为模型训练成果。正式微调策略、长时间训练、生成效果评价和训练报告另开实验，不在本文中宣称完成。
