AnyAccomp云端最小运行包

状态：输入已准备，等待2026年9月11日配置实验室云服务器。本目录不保存服务器地址、账号、密码、私钥或访问令牌。

内容

  • inputs/：三个FT-GAN人声副本，覆盖7.07秒、10.26秒和27.55秒。
  • manifest.csv：来源、音频属性、音量检查和SHA-256。
  • AnyAccomp代码与预训练权重不在本地保存，由云服务器从官方仓库直接下载。

云端固定目录

在服务器配置文档指定的数据盘下创建一个 Gezi-Opera-Synthesis-master-clean 目录，并划分：

source/AnyAccomp/
environments/anyaccomp/
pretrained/anyaccomp/
inputs/
outputs/accompaniment/
outputs/mixture/
logs/

实际绝对路径在服务器配置完成后记录，不把连接凭据写入本目录。

执行顺序

  1. 只读检查系统、GPU、显存、驱动、CUDA、Conda、磁盘和外网访问。
  2. 创建独立Python 3.9环境，不复用当前项目 .venv。
  3. 拉取 https://github.com/AmphionTeam/AnyAccomp.git 并记录提交号。
  4. 下载 amphion/anyaccomp 模型仓库并记录版本与权重哈希。
  5. 先运行官方样例；通过后上传本目录的三个输入样例。
  6. 固定 device=cuda、seed=1024、n_timesteps=50，先short，再medium和long。
  7. 重复运行short，检查固定种子的可复现性。
  8. 下载伴奏、混合音频、配置和日志到 artifacts/pretrained_accompaniment/2026-09-10_AnyAccomp/。

运行记录要求

每次运行单独保存JSON，至少包含：输入文件与SHA-256、代码提交号、模型版本、参数、GPU、开始和结束时间、运行时长、显存峰值、状态、输出路径和错误摘要。

完成前不得把官方演示、计划或空目录写成实际结果。通用伴奏成功只表示预训练链路跑通，不表示已经得到合格的歌仔戏伴奏。

公开副本已将机器路径替换为占位符；运行示例前请按实际环境填写路径。来源 SHA-256 对应脱敏前的源文件，公开副本不是逐字原文。
